# 📊 Dashboard de Vendas no Excel — Xbox Game Pass

## 📌 Sobre o projeto

Este projeto foi desenvolvido para praticar **Excel, análise de dados e criação de dashboards** a partir de uma base de assinaturas do Xbox Game Pass.

A planilha organiza os dados, realiza cálculos e apresenta indicadores em um dashboard para facilitar a análise de faturamento, planos e assinaturas adicionais.

> **Observação:** os dados utilizados neste projeto têm finalidade educacional e de portfólio. O projeto não representa dados oficiais da Microsoft/Xbox nem constitui uma recomendação comercial ou financeira.

## 🎯 Objetivo

Transformar uma base de dados de assinaturas em uma ferramenta de análise no Excel, passando pelas etapas de:

- organização da base;
- definição de perguntas de negócio;
- cálculos e consolidação dos dados;
- criação de indicadores;
- análise de diferentes tipos de plano;
- construção de gráficos;
- desenvolvimento de um dashboard visual.

## 🧩 Estrutura da planilha

A pasta de trabalho contém quatro áreas principais:

| Planilha | Função |
|---|---|
| **Assets** | Paleta de cores, logos e elementos visuais utilizados no dashboard. |
| **Bases** | Base de dados de assinaturas utilizada nas análises. |
| **Cálculos** | Perguntas de negócio, tabelas de apoio e resultados dos cálculos. |
| **Dashboard** | Painel visual com indicadores e gráficos para análise. |

## 📈 Perguntas de negócio trabalhadas

1. Qual é o faturamento total das vendas de planos anuais?
2. Como o faturamento dos planos anuais se divide entre assinaturas com e sem renovação automática?
3. Qual é o total de vendas do **EA Play Season Pass**?
4. Qual é o total de vendas do **Minecraft Season Pass**?
5. Qual é o faturamento total por tipo de plano (**Core, Standard e Ultimate**)?
6. Como evolui o faturamento ao longo dos meses analisados?
