# 📊 Organizador de Declaração de Imposto de Renda

## 📌 Sobre o projeto

Este projeto foi desenvolvido para organizar informações e documentos relacionados à declaração de Imposto de Renda por meio de uma planilha Excel.

A ferramenta reúne diferentes áreas para facilitar o preenchimento, a organização e o acompanhamento das informações necessárias durante a preparação da declaração.

## 🎯 Objetivo

O objetivo é criar uma estrutura organizada para centralizar informações, documentos e dados utilizados na preparação da declaração.

## ⚙️ Funcionalidades

- Cadastro de informações do titular
- Organização de informes
- Registro de notas e documentos
- Checklist de documentos
- Tabelas auxiliares para organização dos dados
- Estruturação das informações em diferentes planilhas

## 🗂️ Estrutura do projeto

O arquivo está dividido nas seguintes planilhas:

- **TITULAR** — informações principais do titular
- **INFORMES** — organização dos informes
- **NOTAS** — registro e acompanhamento de documentos
- **CHECKLIST** — controle dos documentos necessários
- **TABELAS** — tabelas auxiliares utilizadas na organização

## 🛠️ Ferramentas utilizadas

- Microsoft Excel
- Fórmulas e funções
- Validação de dados
- Organização e estruturação de informações
- Formatação de planilhas

## 📚 Conhecimentos praticados

- Organização de dados
- Estruturação de planilhas
- Criação de checklist
- Utilização de tabelas auxiliares
- Controle e acompanhamento de informações
- Construção de uma ferramenta prática no Excel
